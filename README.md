# Maestrr · publications de test

Dépôt de test du gestionnaire de mises à jour Maestrr.

Les préversions publiées ici servent uniquement à valider l’agent de mise à jour sur de vrais serveurs avant une publication officielle dans [maestrr-releases](https://github.com/Maestrr-app/maestrr-releases).

**Ne pas utiliser en production.** Les archives ne contiennent que le dashboard (pages et contrôleur) ; aucune configuration, aucun compte ni secret.
